## Технические особенности текущего сайта

### WordPress-признаки:

- Пути вида `/wp-content/uploads/...`
- Стандартная структура WordPress
- Cookie-баннер с аналитикой (Яндекс.Метрика)

### Проблемы текущего сайта (для улучшения при перестройке):

1. **Отсутствуют alt-тексты у изображений** — все изображения без alt
2. **Дублирующийся контент** — форма захвата повторяется на каждой странице
3. **Тяжёлые страницы** — ~260-300 KB каждая (в основном из-за WordPress-бэкенда)
4. **Зависимость от PHP/MySQL** — хостинг требует серверной инфраструктуры
5. **Cookie-баннер** — добавляет лишний JavaScript
6. **Множество скрытых служебных страниц** (services, blog, news и т.д.)

## Рекомендации по реализации

1. **SSG (Static Site Generation):** Все страницы могут быть статическими, без SSR
2. **Формы:** Использовать серверные эндпоинты (Telegram-бот/webhook) для отправки форм (уже есть `apps-script/` и `telegram-bridge/`)
3. **Изображения:** Оптимизировать через `@astrojs/image`, добавить alt-тексты
4. **Калькулятор:** Реализовать как клиентский React/Vue компонент или на vanilla JS
5. **Карта:** Использовать статическое изображение карты или ленивую загрузку Яндекс.Карт
6. **SEO:** Перенести meta-теги, добавить JSON-LD разметку
7. **Cookie-баннер:** Оставить минимальную версию для аналитики
8. **Avito-страница:** Запросить у клиента текст/скриншот объявления для извлечения дополнительной информации
